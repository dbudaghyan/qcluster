# QCluster Documentation

Welcome to the official documentation for QCluster, a Python library for clustering customer questions using large language models.

This documentation will guide you through the process of installing, configuring, and using QCluster. You will also find detailed information about the library's API and the structure of the evaluation results.

## Table of Contents

- [**Getting Started**](getting_started.md): Learn how to install QCluster and run the clustering pipeline for the first time.
- [**Configuration**](configuration.md): Understand the available configuration options and how to customize the pipeline's behavior.
- [**The Pipeline**](pipeline.md): Get a high-level overview of the clustering pipeline and learn how to customize it.
- [**API Reference**](api_reference.md): Explore the detailed API documentation for the `qcluster` library.
- [**Evaluation Results**](evaluation.md): Learn how to interpret the evaluation results generated by the pipeline.
