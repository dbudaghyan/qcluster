# API Reference

This API reference provides detailed information about the modules, classes, and functions in the `qcluster` library.

## `qcluster.datamodels`

The `qcluster.datamodels` module contains the Pydantic models that define the data structures used throughout the pipeline. These models ensure that the data is consistent and valid at each stage of the process.

### `Sample`

Represents a single data point from the input dataset.

-   **`id`**: `int` - A unique identifier for the sample.
-   **`flags`**: `str` - Flags associated with the sample.
-   **`instruction`**: `str` - The customer question or instruction.
-   **`category`**: `CategoryType` - The original category of the question.
-   **`intent`**: `str` - The intent of the question.
-   **`response`**: `str` - The response to the question.
-   **`embedding`**: `Optional[EmbeddingType]` - The embedding of the instruction.

### `SampleCollection`

A collection of `Sample` objects.

-   **`samples`**: `list[Sample]` - A list of `Sample` objects.
-   **`description`**: `Optional[str]` - A description of the collection, usually generated by an LLM.
-   **`title`**: `Optional[str]` - A title for the collection, also generated by an LLM.

**Key Methods:**

-   `from_csv(csv_file: PathLike)`: Creates a `SampleCollection` from a CSV file.
-   `group_by_category()`: Groups the samples by their category.
-   `update_embeddings(embedding_function: EmbeddingFunctionType)`: Generates embeddings for all samples in the collection.
-   `describe(description_function: DescriptionFunctionType)`: Generates a title and description for the collection using an LLM.

### `Instruction`

Represents a single instruction (question) that is used for clustering. This is a simplified version of the `Sample` model, designed to prevent data leakage.

-   **`id`**: `int` - The ID of the original sample.
-   **`text`**: `str` - The text of the instruction.
-   **`embedding`**: `Optional[EmbeddingType]` - The embedding of the instruction.
-   **`cluster`**: `Optional[ClusterType]` - The cluster ID assigned to the instruction.

### `InstructionCollection`

A collection of `Instruction` objects.

-   **`instructions`**: `list[Instruction]` - A list of `Instruction` objects.
-   **`description`**: `Optional[str]` - A description of the collection (cluster), generated by an LLM.
-   **`title`**: `Optional[str]` - A title for the collection (cluster), generated by an LLM.

**Key Methods:**

-   `from_samples(samples: SampleCollection)`: Creates an `InstructionCollection` from a `SampleCollection`.
-   `update_embeddings(embedding_function: EmbeddingFunctionType)`: Generates embeddings for all instructions.
-   `update_clusters(clustering_function: ClusteringFunctionType)`: Assigns cluster IDs to all instructions.
-   `group_by_cluster()`: Groups the instructions by their assigned cluster ID.
-   `describe(description_function: DescriptionFunctionType)`: Generates a title and description for a cluster.
-   `get_cluster_category(sample_collections: list[SampleCollection], similarity_function: SimilarityFunctionType)`: Determines the most likely original category for a cluster.

### `ClusterOutput`

Represents the final output for a single cluster.

-   **`cluster_id`**: `int` - The ID of the cluster.
-   **`name`**: `str` - The name (title) of the cluster.
-   **`description`**: `str` - A description of the cluster.
-   **`count`**: `int` - The number of instructions in the cluster.

### `ClusterOutputCollection`

A collection of `ClusterOutput` objects.

-   **`outputs`**: `list[ClusterOutput]` - A list of `ClusterOutput` objects.

### `EvaluationResult`

Represents the results of a single evaluation run.

-   Contains paths to all the files generated during the evaluation, such as the confusion matrix, statistics, and reports.

**Key Methods:**

-   `from_folder_path(path: PathLike)`: Loads an `EvaluationResult` from a directory.
-   `add_final_report()`: Generates a final, qualitative report using an LLM.

### `File`, `Folder`, `CSVFile`, `PYCMObject`

These are utility classes for working with files and folders in the evaluation results directory. They provide a convenient way to read and access the content of the different output files.

## `qcluster.algorithms`

The `qcluster.algorithms` module contains the implementations of the various algorithms used in the pipeline, such as clustering, feature extraction, and similarity calculation.

### `clustering`

This module provides functions for clustering the instruction embeddings.

-   **`kmeans_clustering(embeddings: EmbeddingType, n_clusters)`**: Performs K-Means clustering.
-   **`spectral_clustering(embeddings: EmbeddingType, n_clusters)`**: Performs Spectral Clustering.
-   **`dbscan_clustering(embeddings: EmbeddingType, eps=0.5)`**: Performs DBSCAN clustering.
-   **`hdbscan_clustering(embeddings: EmbeddingType, ...)`**: Performs HDBSCAN clustering.
-   **`agglomerative_clustering(embeddings: EmbeddingType, n_clusters=8)`**: Performs Agglomerative Clustering.
-   **`bert_topic_extraction(embeddings: EmbeddingType, ...)`**: Performs topic modeling using BERTopic.

### `feature_extractors`

This module provides functions for extracting features (embeddings) from the text data and for reducing their dimensionality.

-   **`create_embeddings(texts: list[str], model: SentenceTransformer)`**: Creates embeddings for a list of texts using a sentence transformer model.
-   **`pca_reduction(embeddings: torch.Tensor, n_components: int)`**: Reduces the dimensionality of embeddings using PCA.
-   **`umap_reduction(embeddings: torch.Tensor, n_components: int, ...)`**: Reduces the dimensionality of embeddings using UMAP.

### `similarity`

This module provides functions for calculating the similarity between embeddings.

-   **`get_top_n_similar_embeddings(query_embedding, embeddings, top_n=5, ...)`**: Finds the top N most similar embeddings to a query embedding using cosine similarity. It also supports Maximal Marginal Relevance (MMR) for diverse results.

### `dissimilarity`

This module provides functions for selecting a diverse subset of items from a list.

-   **`select_mmr(sentences: list, n: int, lambda_param: float)`**: Selects a diverse subset of N sentences from a list using Maximal Marginal Relevance (MMR).

## `qcluster.llm`

The `qcluster.llm` module contains functions for interacting with large language models (LLMs).

### `ollama`

This module provides a generic function for querying an Ollama-compatible LLM.

-   **`query_llm(template_name: str, data: dict, model: str, ...)`**: Renders a Jinja2 template with the given data, sends it to the specified LLM, and returns the response. It can also validate the output against a Pydantic model.

### `describer`

This module uses an LLM to generate a title and description for a cluster of questions.

-   **`get_description(document: str, template_name: str, ...)`**: Takes a document (a string containing all the questions in a cluster), and uses an LLM to generate a `ClusterDescription` object containing a title and a summary.

### `reporter`

This module uses an LLM to generate a final, qualitative report on the evaluation results.

-   **`create_report(template_name: str, evaluation_result: EvaluationResult)`**: Takes an `EvaluationResult` object, and uses an LLM to generate a detailed report on the clustering performance.
